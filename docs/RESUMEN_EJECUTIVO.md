- **Trastornos del lenguaje:** Descripciones verbales detalladas

## ⚙️ SOLUCIÓN DE PROBLEMAS RÁPIDA

### ❌ Cámara no funciona
```python
# Cambiar en el código:
cap = cv2.VideoCapture(1)  # Probar 0, 1, 2
```

### ❌ No detecta objetos
- Mejorar iluminación
- Usar fondo claro uniforme
- Objetos más grandes (>5cm)
- Colores más vivos

### ❌ Voz no funciona
```bash
# Windows
pip install pyttsx3==2.90

# Linux
sudo apt-get install espeak
```
