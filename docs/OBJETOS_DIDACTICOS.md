## 🎯 Criterios de Selección de Objetos

Los objetos didácticos se seleccionan considerando:

### 1. **Relevancia Pedagógica**
- ✅ Utilidad en el currículo de educación especial
- ✅ Conexión con habilidades de vida diaria
- ✅ Valor educativo claro

### 2. **Accesibilidad**
- ✅ Fáciles de obtener
- ✅ Económicos
- ✅ Seguros para niños
- ✅ Duraderos

### 3. **Progresión de Dificultad**
- **Nivel Básico (3-5 años)**: Objetos simples, comunes
- **Nivel Intermedio (6-8 años)**: Mayor complejidad
- **Nivel Avanzado (9+ años)**: Conceptos abstractos

### 4. **Adaptabilidad**
- ✅ Utilizables con diferentes discapacidades
- ✅ Múltiples aplicaciones pedagógicas
- ✅ Escalables en complejidad

## 📊 Progresión del Aprendizaje

### Fase 1: Reconocimiento Básico (Nivel 1)
- Identificar objetos comunes (3-5 objetos)
- Asociar con colores básicos
- Vocabulario simple

### Fase 2: Clasificación (Nivel 2)
- Agrupar por categorías
- Identificar 10-15 objetos
- Describir características

### Fase 3: Relaciones y Conceptos (Nivel 3)
- Comparar objetos
- Entender funciones
- Formar oraciones completas
- 20+ objetos

## 🔄 Actualización del Catálogo

Para agregar nuevos objetos al catálogo:

1. **Identificar necesidad pedagógica**
2. **Recolectar imágenes** (50-500 por objeto)
3. **Etiquetar dataset** con LabelImg
4. **Entrenar modelo** con YOLOv8
5. **Agregar a `educational_object.py`**
6. **Documentar** en este archivo

## 📚 Referencias Pedagógicas

- **Teoría de Piaget**: Desarrollo cognitivo por etapas
- **Aprendizaje multisensorial**: Visual, auditivo, táctil
- **Zona de Desarrollo Próximo (Vygotsky)**: Andamiaje apropiado
- **Diseño Universal para el Aprendizaje (DUA)**: Múltiples medios de representación

## 🎓 Casos de Uso Educativo

### Ejemplo 1: Sesión de Frutas (Nivel Básico)
```
Objetivo: Reconocer 3 frutas y sus colores
Objetos: Manzana (roja), Plátano (amarillo), Naranja (naranja)
Actividad:
1. Mostrar cada fruta
2. Sistema identifica y anuncia
3. Refuerzo positivo
4. Repetir hasta dominio
```

### Ejemplo 2: Medios de Transporte (Nivel Intermedio)
```
Objetivo: Clasificar vehículos por función
Objetos: Carro, Autobús, Bicicleta
Actividad:
1. Identificar cada vehículo
2. Discutir para qué sirve
3. Comparar características
4. Registro de progreso
```
